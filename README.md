# Storybook UI Component Workbench

A React-based interactive UI component development and preview workbench designed to demonstrate reusable UI components with different states, styles, and configurations.

## Project Overview

Storybook UI Component Workbench provides a centralized environment to explore, preview, and interact with reusable UI components. It helps developers understand component behaviour, visual variations, and design consistency.

## Features

- Interactive component previews
- Reusable UI components
- Multiple component states and variants
- Light and dark themes
- Responsive preview layouts
- Customizable component controls
- Component documentation
- Interactive UI demonstrations

## Components

- Button
- Input
- Switch
- Card
- Badge
- Avatar
- Alert
- Navigation Bar
- Modal

## Technology Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS
- CSS

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/varshithavarma-tech/storybook-ui-component-workbench.git`

2. Navigate to the project folder:

   `cd storybook-ui-component-workbench`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in the terminal.

## Production Build

Run:

`npm run build`
